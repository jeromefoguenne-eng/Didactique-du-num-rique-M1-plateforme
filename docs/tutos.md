# Tutoriels

::: info 💡 Boîte à tutoriels pour le cours
Bienvenue dans l'espace dédié aux **tutoriels pratiques** du cours de Didactique du numérique (Master 1). Vous trouverez sur cette page un ensemble de tutoriels, fiches pas-à-pas et guides techniques spécialement sélectionnés pour vous accompagner dans la prise en main des outils numériques, la réalisation de vos ateliers obligatoires et le développement de votre projet de jeu de société.
:::
