# Plateforme de Didactique du Numérique (Master 1 - HECh / FWB)

Plateforme pédagogique et syllabus augmenté conçus pour le cours de **Didactique du numérique** dispensé en **Master 1 en Pédagogie / Math-Numérique** à la Haute École Charlemagne (Fédération Wallonie-Bruxelles).

- 🌐 **Site en ligne** : [https://jeromefoguenne-eng.github.io/Didactique-du-num-rique-M1-plateforme/](https://jeromefoguenne-eng.github.io/Didactique-du-num-rique-M1-plateforme/)

- 🎓 **Année académique** : 2026-2027

## 🎯 Organisation du Cours & Parcours Asynchrone

La plateforme est structurée en 4 grands axes pour faciliter le travail en présentiel comme à distance (pour les étudiants en horaire adapté ou en fonction) :

1. **Axe 1 : Fondements, Éthique & Référentiel**
   - 00. Penser l'IA & Éthique (Anne Alombert, Gilbert Simondon, Georges Canguilhem)
   - 01. Les compétences numériques (DigComp & Éducation aux médias)
   - 02. Le référentiel FMTTN en Fédération Wallonie-Bruxelles (4 champs & progression spiralaire)
2. **Axe 2 : Ingénierie Didactique & Méthodologies Actives**
   - 03. Enseigner le numérique : Pédagogie par projet, investigation, défi et conception itérative
   - 04. Préparer une leçon FMTTN : Triple concordance de Bloom & Assistant FMTTN HECh
3. **Axe 3 : Le Projet Fil Rouge — Jeu de Société FabLab**
   - 05. Ludopédagogie & Éducation aux médias
   - 06. Mécanique ludique & Rédaction des règles du jeu
   - 07. Photographie, image, éthique et droit à l'image
   - 08. [Jalon 2] Création des cartes de jeu avec l'IA
   - 09. [Jalon 3] Prototypage FabLab (Découpeuse laser & Impression 3D)
   - 10. Réaliser la capsule vidéo de présentation (3-5 min)
   - 11. [Jalon 4] Séances de test (Playtest) & Démarche itérative
4. **Espace Ateliers Pratiques**
   - 7 ateliers méthodologiques avec fiches consignes et **corrigés / débriefings didactiques dépliables**.

## 💻 Développement Local & Mises à Jour

Cette plateforme est propulsée par [VitePress](https://vitepress.dev/). Chaque modification poussée sur la branche `main` déclenche un déploiement automatique sur GitHub Pages via GitHub Actions.

### Commandes utiles :

```bash
# Installation des dépendances
npm install

# Lancer le serveur de développement local
npm run docs:dev

# Compiler pour la production
npm run docs:build

# Prévisualiser la version de production en local
npm run docs:preview
```
